# Documents & Correspondence (MVP1)

## Purpose
Register incoming/outgoing documents, link to cases, keep attachments, and provide template-driven outputs.

## Tables
- T_DocTemplate (minimal MVP1)
- T_Document
- T_DocAttachment

## MVP1 workflow
- Formalities registers IN documents (e.g., OA notice) and attaches PDF scan
- Agent registers OUT documents (e.g., OA reply) and attaches docx/pdf
- (Optional MVP1) document registration can create/close tasks by template trigger (future)
