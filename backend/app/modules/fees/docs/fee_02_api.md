# Fee APIs (MVP1)

Base: `/api/v1/fees`

- GET /fees/drafts
- POST /fees/drafts
- GET /fees/drafts/{id}
- PUT /fees/drafts/{id}
- POST /fees/drafts/{id}/lock
- POST /fees/drafts/{id}/unlock
- POST /fees/drafts/{id}/items
- PUT /fees/items/{item_id}
- DELETE /fees/items/{item_id}

- GET /fees/rates
- POST /fees/rates (Admin)
- PUT /fees/rates/{id} (Admin)
