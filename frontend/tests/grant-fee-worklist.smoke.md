# Grant Fee Worklist Smoke

目标：验证授权费任务看板只做查看、筛选和预留动作入口，不执行状态变化或草单生成。

## 页面

- 路由：`/grant-fee/tasks`
- 页面标题：`授权费任务看板`
- 菜单项：`授权费任务`

## 接口

- `GET /api/v1/grant-fee-tasks/list`

## 验收点

- 页面只展示列表、筛选与预留动作入口
- 用户可见文案均为简体中文
- 不触发任何状态流转动作
- 不触发草单生成
- 不进入账单或文书联动

## 手工 Smoke

1. 登录后打开 `/grant-fee/tasks`
2. 确认页面标题为“授权费任务看板”
3. 确认筛选项包含状态、客户指示、已生成草单、是否逾期、案件编号、到期日期
4. 确认列表字段包含任务编号、案件、状态、到期日、客户指示、官费、服务费、币种、草单、通知、是否逾期
5. 确认“状态操作（预留）”与“草单联动（预留）”仅为占位入口，不会执行实际操作
