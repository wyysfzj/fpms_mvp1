Lifecycle

同一案件的完整演示生命周期

每个阶段都说明客户操作、系统结果、事实边界和最近新增，避免用内部技术术语代替业务价值。

01

客户与案件

主持人话术

从澄岳智造技术（苏州）有限公司、主联系人周岚和同一件发明申请开始。

界面/动作

在客户、联系人和案件的新建页依次创建，再打开案件详情。

输入

CYZN-<run suffix>；周岚 / 知识产权经理 / zhou.lan@chengyue-ip.example；CYIP-CN-INV-<run suffix>；一种柔性制造产线中视觉检测工位的自适应标定方法。

屏幕输出

客户、主联系人、案号、案名和“新建案件 / 尚未递交 / 权利尚未成立 / 已确认”。

预期结果

客户、联系人、案件各一条，后续对象都关联同一客户和案件。

验证

Canonical IA-01/IA-02 校验计数、业务代码、联系人字段、案名和关联；UUID 只作内部技术身份。

事实边界

每次使用全新运行；合成属性由场景边界统一说明，不写进普通业务字段。

本阶段停止条件

业务库不为空、出现重复业务对象、联系人或案件关联不一致。

最近新增

真实业务形态的动态代码贯穿案件、证据和财务链路。

02

文件与递交准备

主持人话术

本阶段验证模板来源、目录行为与递交准备工作包复用；不声称运行时模板预览。

界面/动作

引用后台已校验的模板 provenance，打开文书向导查看 60 条目录，并对当前案件 resolve 两次。

输入

模板代码与文件 SHA-256、OFFICIAL_NOTICE_001…060、当前案件 CYIP-CN-INV-<run suffix>。

屏幕输出

可执行/仅参考目录状态清楚；两次 resolve 指向同一递交准备工作包。

预期结果

目录请求不是 422，工作包类型为递交准备且不重复创建。

验证

Canonical IA-00、IA-03、IA-04 分别校验 provenance、60 行目录和工作包复用。

事实边界

递交准备不等于官方递交；当前 canonical runner 没有运行时模板预览步骤。

本阶段停止条件

模板哈希不匹配、目录数量或行为不符、重复 resolve 产生第二个工作包。

最近新增

模板 provenance、精确目录行为和幂等工作包复用可分别证明。

03

受理与审查

主持人话术

案件状态只由已复核文件推动，不由口头叙述补写。

界面/动作

通过可见附件与复核 UI，依次上传、复核并消费六份文件。

输入

发明专利请求书及申请文件；发明专利申请递交回执；发明专利申请受理通知书；发明专利申请初步审查合格通知书；发明专利申请公布通知书；发明专利申请进入实质审查阶段通知书。

屏幕输出

附件、证据版本、内容哈希、复核状态、消费结果和对应审查投影。

预期结果

六份证据身份独立，递交回执后进入等待受理，后续进入实质审查。

验证

Canonical IA-05 绑定六个角色的文件哈希、复核版本、生命周期消费和页面状态。

事实边界

内部记录外部操作不等于本系统直接向官方提交。

本阶段停止条件

任何证据未复核、身份复用、哈希或消费结果缺失、页面与权威投影不一致。

最近新增

文件版本、复核结果与生命周期活动形成完整可追踪链。

04

第一轮 OA

主持人话术

第一轮通知、期限、答复包、任务和回执拥有一套独立证据身份。

界面/动作

登记通知和期限，resolve 答复包，创建 OA_OUT，验证错误回执 no-write，再归档正确回执。

输入

第一次审查意见通知书；第一次审查意见答复递交回执；确认日期 2026-09-22、来源 MANUAL_OFFICIAL_NOTICE、状态 CONFIRMED。

屏幕输出

答复文件形成后任务仍开放；正确回执后工作包归档且只关闭目标任务。

预期结果

期限五个表面一致；错案与错来源回执均为 4xx 且前后快照相同。

验证

Canonical IA-05 至 IA-08 校验期限、幂等 resolve、唯一关联、错误回执 no-write 与正确归档。

事实边界

确认日期是本轮合成测试输入，不是通用法定期限。

本阶段停止条件

期限三元组缺失或漂移、错误回执写入、OA_OUT 提前关闭任务、关闭非目标任务。

最近新增

错误回执由口头风险变成可证明的 4xx + no-write。

05

第二轮 OA

主持人话术

第二轮不是修改第一轮对象，而是一套独立通知、期限、答复包、任务和回执。

界面/动作

处理第二轮通知、答复与回执，再回看第一轮历史。

输入

第二次审查意见通知书；第二次审查意见答复递交回执；确认日期 2026-10-23、来源 MANUAL_OFFICIAL_NOTICE、状态 CONFIRMED。

屏幕输出

第二轮各项身份与第一轮不同，第二轮任务关闭，第一轮历史保持不变。

预期结果

两轮完整隔离，案件回到实质审查投影。

验证

Canonical IA-09 对比两轮 source/package/task/OA_OUT/receipt，并复核第一轮历史快照。

事实边界

第二轮不得复用第一轮证据或期限；日期仍是合成测试输入。

本阶段停止条件

任一身份重复、第一轮历史变化、不完整期限被接受或错误任务被关闭。

最近新增

两轮 OA 可重复、可追踪且互不污染。

06

授权登记准备

主持人话术

更新来源显式替换原来源；旧任务失效后不能继续写入。

界面/动作

复核原始与更新通知，执行来源替换，验证旧任务四类 409/no-write，并在当前任务记录 PAY。

输入

办理登记手续通知书（原始版本）；办理登记手续通知书（更新版本）；确认日期 2026-11-23 / 2026-11-24。

屏幕输出

案件显示授权登记中；替换关系可追踪；只有更新后的任务可操作。

预期结果

四类旧任务写入均被拒绝；当前 PAY 恰好一条；官费 carrier 仍为 0。

验证

Canonical IA-10 至 IA-12 校验两份来源、supersession、旧任务门禁、PAY 和官费 no-write。

事实边界

授权登记处理中不表示专利已生效；PAY 不生成官费金额或草单。

本阶段停止条件

替换边缺失、旧任务可写、PAY 重复、任何官费对象或金额出现。

最近新增

来源替换具备 durable lineage，过期任务四类写入全部 fail closed。

07

服务费草单

主持人话术

授权任务 PAY 与服务费义务分开；本阶段只使用有来源的 SERVICE 项目。

界面/动作

主持人不共享控制页：仅创建唯一 SERVICE obligation；客户共享费用页与草单页：记录 PAY、创建并锁定草单。

输入

授权登记阶段代理服务费；1,200.00 CNY；rate item code、source ref、source version、source SHA-256。

屏幕输出

客户共享费用页与草单页显示唯一义务、LOCKED 草单、服务费来源与“官方费用：未配置”。

预期结果

草单金额严格等于 bundle amount，只含 SERVICE line，重试不增加第二条义务或草单。

验证

Canonical IA-13 通过控制命令创建后，切到正常费用/草单读页核对权威状态和 provenance。

事实边界

1,200.00 CNY 是 SYNTHETIC_TEST_ONLY 输入，不是官方费用或客户报价；未知官费不写为 0。

本阶段停止条件

控制页进入共享屏幕、服务费来源不匹配、草单未锁定/重复、出现官费金额。

最近新增

义务控制动作与正常费用/草单 UI 明确分离，来源与 no-write 边界可见。

08

客户账单与回款

主持人话术

账单是应收、回款是收到钱、核销才建立两者关系，三个事实不能合并。

界面/动作

主持人不共享控制页：依次触发本地演示专用账单、回款、核销命令；客户共享账单、回款、核销与案件权威读页：每次命令后刷新复核。

输入

AR-CYZN-<run suffix>、RCPT-CYZN-<run suffix>、BTR-CYZN-<run suffix>；金额 1,200.00 CNY。

屏幕输出

先显示 UNSETTLED 与 UNALLOCATED，再显示 SETTLED / FULLY_ALLOCATED / 0.00 CNY。

预期结果

唯一账单、唯一回款、唯一有效核销；重放返回同一业务对象。

验证

Canonical IA-14 至 IA-18 从正常权威读页核对业务号、金额、余额、币种、状态和最终截图。

事实边界

回款登记不等于已经核销；只有有效 offset 才使账单结清。

本阶段停止条件

控制页进入共享屏幕、业务号前缀错误、计数大于 1、回款创建即结清或权威读页不一致。

最近新增

主持人命令与客户可见权威读取分离，财务业务号使用真实形态。

09

后续运维边界

主持人话术

这是口头说明与配置边界：正式模板、官费和年费要有后续明确输入与激活。

界面/动作

本阶段不操作产品页面；主持人回到本说明页口头收口。

输入

无本轮运行时输入；正式客户模板、官费与年费包均未提供或激活。

屏幕输出

无新增产品 UI 观察；仅展示本页的配置边界文本。

预期结果

主持人明确列出未执行事项，不把未来能力讲成当前页面。

验证

本阶段验证的是话术/配置边界；canonical 仅以官费 no-write 和本轮最终状态支持边界，不证明模板或年费 UI。

事实边界

不声称已观察正式模板激活、年费计算、缴费清单或官方支付页面。

本阶段停止条件

任何人把待配置事项描述为已实现、已观察、已激活或已完成。

最近新增

后续范围改为显式 spoken/configuration boundary，不再暗示未观察的 UI。
