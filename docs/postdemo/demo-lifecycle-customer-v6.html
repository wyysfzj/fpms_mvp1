IA-01/IA-02 身份与计数。

08 双草单与服务费调整

演示话术

同案 GOV 与 SERVICE 分轨；官费只读，服务费可追溯调整一次。

UI/操作

查看 GOV 草单；SERVICE OPEN 点击“调整数量”，随后锁定。

输入

FWSQDJ001/FWSQDJ002；数量 1→2；中文原因。

屏幕输出

来源事实、before/after total、活动和两份 LOCKED 草单。

期待结果

GOV 无编辑；SERVICE 1,500.00→1,800.00 CNY。

验证方法

/source-facts 与 adjustment activity。

事实边界

SERVICE 不是官费。

停止条件

可重复调整或锁定后可编辑。

最近新增

双草单与一次审计调整。

09 官费清单与待凭证登记

演示话术

内部登记不等于官方凭证核验。

UI/操作

生成 PayList、逐行登记，再打开正常清单页。

输入

planned amount；收据、凭证、发票均为空。

屏幕输出

已登记，待官方凭证核验。

期待结果

每行一条 GovPayment，无绿色支付成功。

验证方法

GET idempotency 与空凭证字段。

事实边界

不夸大官方事实。

停止条件

Network Error、重复登记或错误成功文案。

最近新增

per-line pending evidence 与 GET-first 恢复。

10 两次客户回款与核销

演示话术

回款与核销是不同对象，分两笔完成。

UI/操作

第一笔回款/核销，刷新余额，再做第二笔。

输入

1,200.00 CNY + authoritative balance 600.00 CNY。

屏幕输出

PARTIALLY_SETTLED → SETTLED；部分结清 → 已结清。

期待结果

两笔回款、两次核销、余额 0.00。

验证方法

1,200.00 + 600.00 = 1,800.00 CNY。

事实边界

登记回款不等于账单核销。

停止条件

回款即结清或未读取权威余额。

最近新增

部分结清到完全结清。

演示话术

UI/操作

屏幕输出

期待结果

最近新增

最近几周成果

runtime 官费来源

生效来源、费率簿版本和 digest 共同约束预览与确认，官费行合计 950.00 CNY。

页面切换采用 network-idle 验证；两轮演练 Network Error 与 console 错误均为空。

客户应记住的三条线

案件与证据

GOV 官费

SERVICE 服务费
