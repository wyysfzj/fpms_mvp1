同一案件，从立案到双轨费用闭环

统一场景：澄岳智造技术（苏州）有限公司；案件“一种柔性制造产线中视觉检测工位的自适应标定方法”。

事实边界：本页数据分级为 SYNTHETIC_TEST_ONLY，使用真实业务形态的合成测试数据，非客户授权、非正式递交、非正式报价、非官方缴费成功、非生产数据。

客户首先看到什么

业务名称清楚

客户详情面包屑显示客户名称；案件列表显示当前阶段与流程状态；文书显示标题、日期、内部文号、回复要求、来源文件和补充说明。

当前事实优先

案件详情首屏按文件、程序、费用三轨回答“现在是什么状态”“最近发生了什么”“下一步是什么”。

审计信息按需查看

“查看完整历史”默认收起；技术标识、摘要和原始状态默认隐藏，显式展开“审计信息”后仍可追溯。

十一阶段客户路线

01 客户与案件

操作

新建客户、主联系人和案件。

屏幕输出

客户名称面包屑；案件列表当前阶段与流程状态。

边界

技术编号不代替业务名称。

02 文件与递交准备

操作

核对文书目录并建立递交准备包。

屏幕输出

结构化文书字段和可执行目录。

边界

准备不等于已经向官方递交。

03 受理与审查

操作

逐份上传、复核并消费六份证据。

屏幕输出

标题、文书日期、内部文号、回复要求、来源文件、补充说明及证据版本。

边界

每份来源独立且可追溯。

04 第一轮审查意见

操作

登记通知、期限、答复包和回执。

屏幕输出

第一轮任务、答复文件和归档状态。

边界

错误回执不得写入。

05 第二轮审查意见

操作

完成独立的第二轮通知、答复和回执。

屏幕输出

第二轮身份与保持不变的第一轮历史。

边界

两轮不得复用证据。

06 授权登记准备

操作

核对更正通知替代关系和当前任务。

屏幕输出

首次申请规则显示为历史核验；当前阶段为授权登记。

边界

历史缺失不冒充当前阻断，旧任务不可写。

07 生效官费预览

操作

点击“预览官费”，核对两行金额后点击“确认官费”。

屏幕输出

900.00 + 50.00 = 950.00 元，两个按钮可见可点。

边界

候选预览，尚未形成缴费义务。

08 双草单与服务费调整

操作

官费只读；服务费数量由 1 调整为 2 后锁定。

屏幕输出

服务费从 1,500.00 元变为 1,800.00 元。

边界

服务费不是官费，调整必须留下审计活动。

09 官费清单与待凭证登记

操作

生成两行官费清单并登记计划金额。

屏幕输出

已登记，待官方凭证核验。

边界

内部登记不等于官方支付成功。

10 两次客户回款与核销

操作

先核销 1,200.00 元，刷新后再核销 600.00 元。

屏幕输出

部分结清后余额 600.00 元，最终已结清且余额为零。

边界

登记回款不等于账单核销。

11 同案双轨汇总

操作

核对文件、程序、费用三轨当前摘要，再按需展开完整历史。

屏幕输出

官费仍待凭证；服务费已结清；审计信息按需展开。

边界

服务费结清不代表官费凭证已核验。

客户应记住的三条线

文件线

结构化文书、证据版本、复核和回执可追溯。

程序线

当前阶段优先；历史规则明确标注历史适用性。

费用线

官费待官方凭证，服务费通过两次回款和核销结清。

完整历史只用于追溯，不替代首屏当前摘要，也不改变任何业务事实。
