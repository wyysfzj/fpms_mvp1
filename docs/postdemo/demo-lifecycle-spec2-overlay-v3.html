讲解规则：三条线同时出现，但案件生命周期主线居中

一、案件生命周期主线

无案卷 → 未递交 → 等待受理 → 实审中 → 一通或二通阶段 → 实审中 → 已授权 → 维持有效 → 年费监控。

同时解释三类状态：案件业务状态、法律状态、工作包/文件状态，不混用英文代码。

二、文件驱动主线

技术交底书、委托指示、Word、XML压缩包、合并PDF、官方来文、OA意见陈述Word、PDF保真附件、修改后的权利要求书、修改对照页、其他证明文件、电子申请回执、授权通知、信函/格式函交接。

三、官费节点主线

只讲官费，不讲“管费”。费用项目对应费用大类，费用细分类型对应费用小类；金额从费率参数表维护，0.85 表示减缴 85%，实际缴纳 15%。

V4 官费节点覆盖：为什么产生、何时产生、金额和期限依据

费用节点 触发文件或状态 金额依据 期限依据 演示边界
新申请官费 新申请递交准备包具备提交条件。 发明申请费 900；公布印刷费、申请附加费按页数、项数、幅数和费率参数表计算。 按客户文档口径展示申请日或受理通知起 2 个月。 人员仍在官方系统完成缴费或提交，系统只做准备、提示和清单。
实审费 发明进入实审请求或实审提醒节点。 发明实审费按费率参数表计算；如减缴 85%，演示实际缴纳 15%。 按实审请求和官方期限规则展示。 不承诺自动提交实审请求。
复审费 收到驳回决定后，由代理人或流程人员决定是否请求复审。 复审费发明 1000；是否减缴由费用项目减缴范围控制。 驳回决定起 3 个月。 P1.5 只做复审触发预览，不自动创建复审工作包、不自动提交。
授权费与年费 授权通知入库，授权日、授权号、首年年费年度和有效期补齐。 授权相关官费、授权当年起 10 年内年费按参数表和费减规则计算；滞纳金按当年全额年费每月 5% 预览。 授权/年费期限预览展示起算文件、期限规则和应处理日期。 形成授权费任务、年费任务和年费清单，不承诺自动缴费。
PCT / Hague / IC_LAYOUT 只在设计说明中展示参数化规则冻结。 可在参数表维护已知费率，但不启用自动触发。 进入 P2/P3 后再依据客户样例和字段确认。 本轮 demo 明确不演示自动触发，避免误承诺。

实际演示脚本：每一步先说预期，再操作页面

步骤 演示前法律状态 要操作的页面或动作 演示后应看到 客户应理解的价值
新案立案 无 → 未递交 打开案件详情，展示申请人、发明人、总委托书备案编号、技术交底书。 案件为未递交；技术交底书为必备文件，委托指示为条件文件。 稳定字段在系统维护，不靠递交前临时补录。
递交准备 未递交 进入新申请递交准备，核对字段、文件清单、官方页面操作清单。 递交包可人工提交；提交回执或合并文件归档后，状态进入等待受理。 工作人员不重复查字段、不重复整理文件。
受理与实审 等待受理 展示受理或实审相关官文，以及发明申请费 900、公布印刷费、申请附加费或实审费草单。 案件进入实审中；官费节点随官文或事件出现，费率来自参数表。 案件状态、官文和官费不是三套孤立记录。
收到审查意见 实审中 → 一通或二通阶段 从审查意见来文进入答复工作包；补充说明驳回决定后的复审费发明 1000 预览。 显示答复期限、待答复文件、保真附件、官方页面操作清单和复审触发边界。 系统把答复所需材料集中，不让人员跨页面拼信息，也不把复审自动化误说成 P1。
答复归档 一通或二通阶段 → 实审中 上传答复回执，核对接收案件编号、提交人、接收时间和收到文件清单。 答复工作包归档，内部任务关闭，案件回到实审中。 不是生成内部答复文件就算完成，必须有官方回执证据。
授权状态变化 实审中 → 已授权 上传或登记授权通知，补齐授权日、授权号、首年年费年度、有效期。 法律状态转为已授权；授权费任务出现。 甲方能看到文件如何驱动授权状态，而不是手工改状态。
授权费清单 已授权 进入授权费或官费清单页面，展示授权费草单、清单、缴费登记字段和授权/年费期限预览。 授权费从任务到草单再到清单形成闭环，并说明期限起算依据。 官费节点跟随案件生命周期出现，金额和期限都可追溯。
年费任务与清单 已授权 → 维持有效 进入年费任务，展示客户缴费指示、年费草单、年费官费清单和滞纳金预览。 系统展示未来年费任务；缴费指示为“缴费”时形成年费清单，案件进入年费监控。 授权后系统继续管理维持，不让年费变成线下表格工作。
演示边界：本轮只说明系统如何准备材料、集中字段、驱动状态、形成官费节点和归档证据；不承诺自动登录官方系统、不承诺自动扫码签名、不承诺自动提交、不承诺自动缴费、不承诺龙虾邮件自动发送。
