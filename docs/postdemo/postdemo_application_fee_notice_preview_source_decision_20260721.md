# 申请费通知书官方费用预览——客户来源决定记录

日期：2026-07-21  
状态：待客户确认  
用途：为申请费通知书的官方费用预览提供明确、可审计且可重放的数量来源。

## 已确认且不再询问的边界

- 官费金额、费率簿、减缴资格和生效日仍由已经批准的系统费率与减缴凭证决定。
- 客户端不得输入或上传所谓“官方预览金额”。
- 系统不得用通知书金额除以单价来反推数量，不得从案件类型、文件名或当前可变数据猜测。
- 未确认、缺失、冲突或过期时，系统必须停止申请费通知 dispatch，不得形成已接受官费义务。
- 本决定只暂停申请费通知 dispatch，不影响期限补偿、PayList、年费或其他案件流程。

## 待客户确认的三项来源

### 1. 说明书页数

- 说明书页数以哪个正式文书、XML 字段或已审核系统字段为准：待客户确认。
- 该数字是否包含说明书附图页数：待客户确认。
- 修订稿、补正稿与首次提交稿并存时，使用哪个版本及其审核状态：待客户确认。

### 2. 附图页数及分档

- 附图页数是否参与第 31-300 页与第 301 页以上的计算：待客户确认。
- 30、31、300、301 页四个边界示例的期望数量：待客户确认。
- 来源缺失、无法解析或多个当前版本并存时的处理必须是 fail-closed；不得反推数量。

### 3. 优先权项数

- 优先权项数以 XML、已审核优先权记录、官方文书还是其他字段为准：待客户确认。
- 撤回、失效、重复、未确认或非当前优先权记录是否计数：待客户确认。
- 多项优先权的去重键、排序和当前性规则：待客户确认。

## 客户确认时必须提供

1. 每项来源的正式名称和字段/文书/XML 路径；
2. 当前版本、审核状态和生效日要求；
3. 缺失、冲突、无法解析时是否一律停止；
4. 上述四个页数边界及 0/1/多项优先权的实例；
5. 确认人、确认时间和可追溯的原始反馈或附件。

carrier 和申请费通知 dispatch 不得开始。
