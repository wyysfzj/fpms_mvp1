## Delta-2 overlay contract

`delta_overlay.json` is deterministic and contains no clock field. It must contain:

- `parents`: path and SHA-256 for the immutable baseline catalog/indexes and the accepted
  delta-1 manifest/overlay; parent bytes and hashes must not change;
- `approved_delta_spec`: delta-2 spec path and SHA-256;
- `external_prerequisites`: exactly rows 01 and 04, with task ID/path, closure,
  dependencies, product allowlist and current task hash;
- `contract_overrides`: exactly the 22 existing task IDs in rows 02–03 and 05–24,
  with old/new dependency lists, closure, product allowlist and current task hash;
- `serialization_overrides`: lifecycle registry, evidence policy, complete nine-owner
  document-service chain, system API/schema, fee API/types, overlay service 1..5,
  CaseLifecycleOverlay Vue 1..3, frontend full-typecheck order, SQLite global queue,
  Playwright `--workers=1`, Full manifest ownership, and final ledger/close order;
- `effective_graph`: 283 baseline nodes + 3 accepted delta-1 external nodes + 2 delta-2
  external nodes = 288 unique nodes, zero unresolved references and zero cycles;
- `effective_foundation_close_requirements`: immutable 197 Foundation IDs plus all five
  external prerequisite IDs = 202; do not rewrite the 197-row manifest;
- `downstream_close_requirements`: both controllers/overlays and all five external task
  gates/evidence must reach Foundation, full item/slice ledger and final close;
- `manifest_rows`: exactly rows 01–25 once each.

The validator fails closed on parent hash drift, missing/duplicate row, task-hash drift,
wrong counts, unresolved dependency, cycle, shared-owner inversion, gate-code-only dedup,
ALL-22 as a public request, or any Foundation/Full/Release bypass.
