# ENH-06-03 — Fees service: draft CRUD + list/get + totals recalculation

## Context
Review report requires a service layer (P0) and highlights data integrity risks without validation/transactions.

## Target (Atomic)
- File: `backend/app/modules/fees/service.py`

## Allowlist
- `backend/app/modules/fees/service.py` ONLY

## Non-scope
- No API changes
- No schemas changes
- No DB/migration changes

## Required implementation (EXACT)
Implement the following functions in `fees/service.py`:

1) `list_fee_drafts(db, *, filters: dict, page: int, page_size: int) -> tuple[list[T_FeeDraft], int]`
   - Filters supported: `case_id`, `client_id`, `status`
   - Apply pagination and return `(items, total)`
   - Order by `updated_at DESC` (or `created_at DESC` if needed)

2) `get_fee_draft(db, *, draft_id: str) -> T_FeeDraft`
   - Must raise project-standard not-found error (e.g., `BusinessError(code="NOT_FOUND", ...)`) if missing

3) `create_fee_draft(db, *, data: FeeDraftCreateIn, actor_id: str | None) -> T_FeeDraft`
   - Create `t_fee_draft` row with:
     - `status = FeeDraftStatus.OPEN`
     - totals initialized to 0
   - Validate FK existence if applicable:
     - `case_id` exists in `t_case`
     - `client_id` exists in `t_client`
   - Commit and refresh

4) `update_fee_draft(db, *, draft_id: str, data: FeeDraftUpdateIn, actor_id: str | None) -> T_FeeDraft`
   - Update only provided fields (exclude unset)
   - MUST NOT update status here
   - Commit and refresh

5) `recalc_fee_draft_totals(db, *, draft_id: str) -> None`
   - Compute sums of `t_fee_item.amount` grouped by `fee_type` for this draft
   - Update draft fields:
     - `total_gov`, `total_service`, `total_misc`
     - `amount = total_gov + total_service + total_misc`
   - Commit

Notes:
- Use SQLAlchemy ORM models already defined in `fees/models.py` (class names may vary; table names are `t_fee_draft/t_fee_item/t_fee_rate`).
- Use `Decimal` arithmetic (avoid float).
- Do not add new columns.
