## Required implementation (EXACT)

Implement the following functions in `tasks/service.py` using SQLAlchemy ORM models:

1) `list_tasks(db, *, filters: dict, page: int, page_size: int) -> tuple[list[T_Task], int]`
   - Supported filters (keys in `filters` dict):
     - `status`
     - `case_id`
     - `worker_id`
     - `supervisor_id`
     - `due_from` (date, inclusive)
     - `due_to` (date, inclusive)
   - Must apply pagination: offset = (page-1)*page_size, limit=page_size
   - Must return `(items, total)` where total is total matching count without pagination
   - Default ordering: `due_date ASC, created_at DESC` (if columns exist)

2) `get_task(db, *, task_id: str) -> T_Task`
   - Raise a consistent not-found error (use project’s existing error pattern; e.g., `BusinessError(code="NOT_FOUND", ...)` if available)
   - Must NOT return None

3) `create_task(db, *, data: TaskCreateIn, actor_id: str | None) -> T_Task`
   - Create `T_Task`
   - Default `status = TaskStatus.OPEN`
   - Validate FK existence if provided:
     - `case_id` -> `T_Case`
     - `document_id` -> `T_Document`
     - `task_template_id` -> `T_TaskTemplate` (and enabled if such column exists)
   - Persist and return ORM task

4) `update_task(db, *, task_id: str, data: TaskUpdateIn, actor_id: str | None) -> T_Task`
   - Update only provided fields (exclude unset)
   - Must NOT allow status change here
   - Validate FK existence for changed FK fields (case/document/template)
   - Persist and return updated task
