## Target
- **File**: `backend/app/api/router.py`
- **Atomic rule**: Modify ONLY this file to ensure `auth_router` is correctly included.

## Scope decision (MVP1 – FIXED)
- Ensure the `POST /auth/login` route is registered in `router.py`.
- Use `include_router(auth_router, prefix="/auth", tags=["Auth"])`.
- Do **NOT** modify any other files or introduce new endpoints.

## Components to implement (EXACT)
1. In `backend/app/api/router.py`, add the following to correctly wire the `auth_router`:
   ```python
   from app.modules.auth.api import router as auth_router

   # Include the auth router with the correct prefix and tags
   router.include_router(auth_router, prefix="/auth", tags=["Auth"])
   ```

2. Ensure `auth_router` is properly imported from `app/modules/auth/api.py`.

## Non-scope (explicitly excluded)
- Do **NOT** modify `api.py` or add new logic to the `POST /auth/login` endpoint.
- Do **NOT** modify authentication logic, role-based permission checks, or any other models.
