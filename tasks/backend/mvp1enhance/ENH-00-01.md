## Scope decision (MVP1 – FIXED)
- Implement consistent error handling framework per architecture spec.
- This task ONLY creates error exception classes and helpers.
- No endpoint changes, no API modifications.

## Components to implement (EXACT)
1. **Pydantic Models**:
   - `ErrorDetail(BaseModel)` with fields: `code: str`, `message: str`, `details: dict | None = None`
   - `ErrorResponse(BaseModel)` with field: `error: ErrorDetail`

2. **Exception Class**:
   - `BusinessError(Exception)` with attributes:
     - `code: str`
     - `message: str`
     - `details: dict | None = None`
     - `status_code: int = 400`

3. **Helper Functions**:
   - `raise_business_error(code: str, message: str, details: dict | None = None, status_code: int = 400) -> None`
     - Raises `BusinessError` with given parameters
   - `to_error_response(code: str, message: str, details: dict | None = None) -> dict`
     - Returns dict in format: `{"error": {"code": "...", "message": "...", "details": {...}}}`

## Non-scope (explicitly excluded)
- Exception handler registration (that's ENH-00-02)
- Modifying existing API endpoints
- Adding logging
