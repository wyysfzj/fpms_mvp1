### Draft schemas
1) `FeeDraftCreateIn`
   - `case_id: str` (required if NOT NULL)
   - `client_id: str` (required if NOT NULL)
   - `draft_type: str | None = None` (if DB has default, allow None)
   - `currency: str` (required if NOT NULL)

2) `FeeDraftUpdateIn` (all optional)
   - `draft_type: str | None = None`
   - `currency: str | None = None`
   - NOTE: status is not updated here (lock/unlock endpoints control status)

3) `FeeDraftOut` (ORM)
   - `id: str`
   - `case_id: str`
   - `client_id: str`
   - `draft_type: str`
   - `currency: str`
   - `status: FeeDraftStatus`
   - `total_gov: Decimal`
   - `total_service: Decimal`
   - `total_misc: Decimal`
   - `amount: Decimal`
   - `created_at: datetime`
   - `updated_at: datetime`

4) `FeeDraftListItemOut` (minimal list projection)
   - `id, case_id, client_id, currency, status, amount`

### Item schemas
5) `FeeItemCreateIn`
   - `rate_id: str` (required)
   - `year_no: int | None = None`
   - `quantity: Decimal | None = None`
   - `unit_price: Decimal | None = None`
   - `remark: str | None = None`

6) `FeeItemUpdateIn` (all optional)
   - `year_no, quantity, unit_price, remark`

7) `FeeItemOut` (ORM)
   - `id: str`
   - `draft_id: str`
   - `case_id: str`
   - `rate_id: str`
   - `fee_code: str`
   - `fee_name: str`
   - `fee_type: FeeType`
   - `year_no: int | None`
   - `quantity: Decimal | None`
   - `unit_price: Decimal | None`
   - `amount: Decimal`
   - `remark: str | None`

### Rate schemas (fee rate management)
8) `FeeRateCreateIn`
   - `fee_code: str`
   - `fee_name: str`
   - `fee_type: FeeType`
   - `currency: str`
   - `default_amount: Decimal`
   - `enabled: bool = True`

9) `FeeRateUpdateIn` (all optional)
   - `fee_name, fee_type, currency, default_amount, enabled`

10) `FeeRateOut` (ORM)
   - `id, fee_code, fee_name, fee_type, currency, default_amount, enabled`

### Generic action response
11) `OkOut`
   - `status: str = "ok"`

### Imports / config
- Import `FeeType`, `FeeDraftStatus` from `fees/enums.py`
- Use `ConfigDict(from_attributes=True)` for ORM outputs
- Use `Decimal` from `decimal` module; set JSON encoders if your project requires
