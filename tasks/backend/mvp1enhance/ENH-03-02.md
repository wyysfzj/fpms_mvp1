
# ENH-03-02 — Implement Billing Service Layer

## Goal
Create the billing service layer to handle bill generation, payment processing, and bill status transitions.

## Scope
- Implement the service layer in **`billing/service.py`**.
- Ensure the business logic for bill generation, payment handling, and status transitions is moved out of the API layer.

## Required Steps
1) In `billing/service.py`, implement the following functions:
   - `generate_bill()`: For generating a new bill based on inputs.
   - `process_payment()`: For processing payments and updating balances.
   - `update_bill_status()`: For transitioning bill statuses (e.g., from `pending` to `paid`).
2) Ensure the service layer interacts with the models and handles transactions.

## Acceptance Criteria
- [ ] Service layer functions are implemented correctly.
- [ ] All business logic is encapsulated in the service layer.
- [ ] Proper error handling and transaction management are implemented.

## Evidence Required
- `ruff check` and `python3 -m py_compile` outputs for `service.py`.
- `git diff` showing only changes in `service.py`.

## Verification
```bash
cd backend
ruff check app/modules/billing/service.py
ruff format app/modules/billing/service.py
python3 -m py_compile app/modules/billing/service.py
cd ..
```
