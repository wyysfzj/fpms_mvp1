## Goal
1) Make it possible to collect objective evidence for each task under `artifacts/<TASK-ID>/...`
2) Enforce **Task Gate** and **Release Gate** deterministically
3) Ensure strict-scope tasks (e.g., ENH-00-01) can pass gates **without** expanding their allowed code scope

## Components to implement (EXACT)

### A) Evidence runner (required)
Create `scripts/evidence_run.sh`:
- Usage: `./scripts/evidence_run.sh <TASK-ID> <step> <command...>`
- Creates: `artifacts/<TASK-ID>/outputs/`
- Writes:
  - `artifacts/<TASK-ID>/commands.jsonl` (one JSON per command invoked)
  - `artifacts/<TASK-ID>/results.jsonl` (ts, step, rc, log path)
- Captures stdout/stderr into `artifacts/<TASK-ID>/outputs/<timestamp>_<step>.log`
- Exits non-zero if the wrapped command fails

### B) Evidence finalize (required)
Create `scripts/evidence_finalize.sh`:
- Usage: `./scripts/evidence_finalize.sh <TASK-ID>`
- Writes git evidence:
  - `artifacts/<TASK-ID>/git/diff.patch`
  - `artifacts/<TASK-ID>/git/status.txt`
  - `artifacts/<TASK-ID>/git/rev.txt`
- Creates `artifacts/<TASK-ID>/summary.md` if missing (template skeleton)
- Must be safe to run multiple times

### C) Task Gate (required)
Create `scripts/task_validate.sh`:
- Usage: `./scripts/task_validate.sh <TASK-ID>`
- Validates existence of:
  - `artifacts/<TASK-ID>/summary.md`
  - `artifacts/<TASK-ID>/results.jsonl`
  - `artifacts/<TASK-ID>/git/diff.patch`
- Validates that `results.jsonl` contains:
  - lint step rc=0
  - test step rc=0
- Treat e2e as informational: pass even if no e2e entry exists

### D) Release Gate (required)
Create `scripts/release_gate.sh`:
- Usage: `./scripts/release_gate.sh`
- Behavior:
  - Iterates over `artifacts/ENH-*` and runs `scripts/task_validate.sh` for each
  - Fails if any task gate fails
  - Prints a short summary

### E) Repo hygiene (required)
- Create `artifacts/.gitkeep`
- Update `.gitignore` to include: `artifacts/`

## 12) Evidence & Gates (EOS Bootstrap — MVP1 Enhancement)

To make AI-first execution auditable and deterministic, every task MAY create/update evidence under:

- `artifacts/<TASK-ID>/**`

This is **non-product output** and is explicitly allowed for all tasks, even when a task’s code scope is restricted to a single source file.

Rules:
- Do NOT store secrets/PII in artifacts logs.
- Artifacts should be generated by wrapper scripts (see `scripts/evidence_run.sh`).
- Evidence is required for tasks that claim completion:
  - `artifacts/<TASK-ID>/results.jsonl` (commands + rc)
  - `artifacts/<TASK-ID>/summary.md` (human-readable evidence summary)
  - `artifacts/<TASK-ID>/git/diff.patch` (scoped diff)

Gates:
- Task Gate: `./scripts/task_validate.sh <TASK-ID>`
- Release Gate: `./scripts/release_gate.sh`
