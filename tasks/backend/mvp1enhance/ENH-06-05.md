# ENH-06-05 — Fees service: fee item add/update with validation + totals refresh

## Context
Review report requires fee item CRUD (P0) and item validation. Also, edits must be blocked when draft is locked.

## Target (Atomic)
- File: `backend/app/modules/fees/service.py`

## Allowlist
- `backend/app/modules/fees/service.py` ONLY

## Non-scope
- No API changes
- No schema changes
- No DB/migration changes

## Required implementation (EXACT)
Implement in `fees/service.py`:

1) `add_fee_item(db, *, draft_id: str, data: FeeItemCreateIn, actor_id: str | None) -> T_FeeItem`
   - Load draft; call `assert_draft_unlocked(draft)`
   - Validate rate exists (`t_fee_rate`) and `enabled == True`
   - Enforce currency match:
     - draft.currency == rate.currency (else BusinessError `FEE_CURRENCY_MISMATCH`)
   - Create `t_fee_item` with:
     - `draft_id = draft_id`
     - `case_id = draft.case_id`
     - `rate_id = rate.id`
     - `fee_code/fee_name/fee_type` copied from rate
     - `year_no = data.year_no`
     - `quantity = data.quantity` (if None, treat as 1 for amount calc)
     - `unit_price = data.unit_price` (if None, default to rate.default_amount)
     - `amount = quantity * unit_price` (Decimal)
     - `remark = data.remark`
   - Commit
   - Call `recalc_fee_draft_totals(draft_id=...)`

2) `update_fee_item(db, *, draft_id: str, item_id: str, data: FeeItemUpdateIn, actor_id: str | None) -> T_FeeItem`
   - Load draft; enforce unlocked
   - Load item by item_id and ensure `item.draft_id == draft_id` else NOT_FOUND
   - Update only provided fields (`year_no`, `quantity`, `unit_price`, `remark`)
   - Recompute `amount` after any `quantity` or `unit_price` change (use current values + defaults)
   - Commit
   - Recalc totals

Notes:
- Do NOT allow changing `rate_id` in update (out of scope).
- Raise BusinessError for not-found / validation errors (avoid 500).

## Acceptance checklist
- [ ] Only service.py changed
- [ ] add/update enforce draft unlocked and currency match
- [ ] draft totals refresh after item changes
