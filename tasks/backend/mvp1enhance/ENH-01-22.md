# ENH-01-22 — Implement get_current_user and require_perm

## Context / Why
In order to properly authenticate and authorize users within the FPMS platform, two core functions are needed: `get_current_user` and `require_perm`.
- `get_current_user` retrieves the currently authenticated user from the database.
- `require_perm` checks if the user has the necessary permission for a specific action.

These functions are essential for implementing secure and role-based access control across various endpoints.

## Target (Atomic – FIXED)
Implement `get_current_user` and `require_perm` functions to be used in FastAPI endpoints for user authentication and authorization.

## Allowed files (Strict allowlist)
- `backend/app/core/dependencies.py` ONLY

## Non-scope (explicitly excluded)
- Do NOT modify `auth/api.py`
- Do NOT modify `routers.py`
- Do NOT modify migrations/DB/seed files

## Required change (EXACT)
1. **get_current_user function**: 
   - Implement `get_current_user` to return the authenticated user from the database.
   - Use `Depends` for FastAPI dependency injection.

2. **require_perm function**:
   - Implement `require_perm` to verify the user's permission based on a given permission code.
   - Raise an HTTP 403 error if permission is not granted.

3. Ensure that both functions are integrated into the appropriate API routes to enforce user authentication and permissions.
