# ENH-11-03 — Testing: integration tests for core behaviors (auth, RBAC, error envelope, pagination)

## Context / Why
Review report item 11.3 asks for integration tests for key flows.
This task covers the cross-cutting guarantees:
- login works
- RBAC returns 403 when missing perm
- error envelope format is stable
- PageResult generic works and list endpoints return pagination shape

## Allowed files (Strict allowlist)
- `backend/tests/test_core.py` (CREATE OR MODIFY) ONLY

## Required change (EXACT)
Create `backend/tests/test_core.py` with tests:

1) `test_login_success_returns_token`
- POST /api/v1/auth/login with admin credentials
- assert 200 and response contains `access_token`

2) `test_auth_required_returns_401_error_envelope`
- GET /api/v1/documents without auth
- assert 401 and JSON has `error.code` + `error.message`

3) `test_forbidden_returns_403_error_envelope`
- Simulate missing perm:
  - either call an endpoint requiring a perm that admin test user lacks (if you seeded limited perms)
  - OR override require_perm dependency in conftest to enforce a missing perm for this one test
- assert 403 and JSON includes `error.details.required_perm`

4) `test_pagination_shape_on_list_endpoint`
- call any list endpoint that exists (e.g., /api/v1/fees/rates or /api/v1/clients)
- assert response JSON has `items/page/page_size/total`
