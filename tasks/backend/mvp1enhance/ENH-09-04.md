# ENH-09-04 — Safe local storage helpers

## Context / Why
Cross-cutting infra item **9.3**: documents module requires safe file operations (path traversal prevention).

## Goal
Create `backend/app/core/storage.py` with safe local storage utilities.

## Allowed Files (Strict allowlist)
- `backend/app/core/storage.py` (CREATE OR MODIFY) ONLY

## Requirements (EXACT)
In `backend/app/core/storage.py` implement:

1) `ensure_dir(path: str) -> None`
- Create directory if missing (idempotent)

2) `safe_join(base_dir: str, *parts: str) -> str`
- Join path parts under base_dir
- MUST prevent `..` traversal / escaping base_dir
- Raise `ValueError` if final path is outside base_dir

3) `save_upload_file(upload_file, dest_path: str) -> tuple[str, int]`
- Save a FastAPI `UploadFile` to dest_path
- Ensure parent dir exists
- Return `(mime_type, size_bytes)`
- Use stdlib only (plus FastAPI UploadFile typing if needed)

## Acceptance Criteria
- [ ] Only `backend/app/core/storage.py` changed/created
- [ ] `safe_join` blocks traversal attempts
- [ ] `py_compile` passes
