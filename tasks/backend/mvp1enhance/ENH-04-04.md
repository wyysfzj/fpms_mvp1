## Requirements (EXACT)
In `documents/service.py`, implement (or complete) **ONLY**:

### Function: `list_documents`
Implement a function that:
- Accepts DB session and pagination args
- Accepts filters for:
  - `q` (search text)
  - `direction`
  - `doc_template_id`
  - `case_id`
  - `date_from` / `date_to`
- Returns `(items, total)` where:
  - `items` is the current page list of Document ORM rows
  - `total` is total count for the given filters (before pagination)

Implementation constraints:
- Use SQLAlchemy 2.x `select()` patterns (no raw SQL).
- Sorting: deterministic (recommended: `doc_date desc`, then `created_at desc`, then `id desc`).
- Filters:
  - `q` should match at least title and ref_no (case-insensitive where possible).
- Pagination:
  - `page` is 1-based; convert to offset `(page-1)*page_size`.
  - Clamp `page_size` to a reasonable upper bound (e.g., 200) **only if** there is an existing project convention; otherwise keep as provided.

Non-scope:
- No API routes here
- No file uploads here
- No schema edits here
