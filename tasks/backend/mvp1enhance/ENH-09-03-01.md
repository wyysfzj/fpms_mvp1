# ENH-09-03-01 — Fix PageResult to support generics (PageResult[T])

## Context / Why
After executing ENH-09-03 (pagination helpers), server startup fails with:

```
TypeError: <class 'app.core.pagination.PageResult'> cannot be parametrized because it does not inherit from typing.Generic
```

This is triggered by existing code such as:
- `class DocumentListOut(PageResult[DocumentOut]): ...`

So `PageResult` MUST support parametrization (`PageResult[T]`).

## Target (Atomic – FIXED)
Modify `PageResult` to be a **generic** Pydantic model compatible with Pydantic v2.

## Allowed Files (Strict allowlist)
- `backend/app/core/pagination.py` (MODIFY) ONLY

## Non-scope
- Do NOT modify documents schemas or any other module
- Do NOT change endpoints
- Do NOT add new dependencies

## Required change (EXACT)
In `backend/app/core/pagination.py`:

1) Add:
- `from typing import Generic, TypeVar`
- `T = TypeVar("T")`

2) Change `PageResult` to inherit `Generic[T]` and type `items` as `list[T]`:

```python
class PageResult(BaseModel, Generic[T]):
    items: list[T]
    page: int
    page_size: int
    total: int
```

3) Keep `PageParams` and `offset_limit()` behavior unchanged.
