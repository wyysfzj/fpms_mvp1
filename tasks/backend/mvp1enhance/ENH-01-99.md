# ENH-01-99 — RBAC Permission Sync (scan + Admin full + delta report)

## Context / Why
We frequently hit 403 FORBIDDEN due to mismatches between:
- Permission codes enforced in code via `require_perm("X.Y")`
- Permission codes actually seeded into `t_role_perm` via `ROLE_PERMISSIONS`

This atomic task introduces a deterministic, auditable workflow:
1) Scan the codebase for all `require_perm("...")` permission codes
2) Compare with `ROLE_PERMISSIONS` (Admin + other roles)
3) Patch **Admin only** to include the full set (so dev testing can proceed)
4) Output a **delta report** for other roles (do NOT modify them)

## Target (Atomic – FIXED)
- Add a permission scanner/report script.
- Update the seed source-of-truth to grant **Admin** all scanned permission codes.
- Generate a delta report (stdout) showing missing codes per role (report-only).

## Allowed files (Strict allowlist)
- `backend/scripts/scan_perms.py` (NEW)
- `backend/app/modules/rbac/service.py` (ONLY if `ROLE_PERMISSIONS` is defined here)
  - If `ROLE_PERMISSIONS` is located elsewhere, STOP and report the correct file path before changing anything.

## Non-scope (explicitly excluded)
- Do NOT change `require_perm()` implementation
- Do NOT change auth/JWT logic
- Do NOT modify DB schema/migrations
- Do NOT change permissions for roles other than "Admin"
- Do NOT refactor or reformat repository-wide

## Required change (EXACT)

### A) Add scanner/report script (NEW): `backend/scripts/scan_perms.py`
The script MUST:
- Recursively scan `backend/app/` for both patterns:
  - `require_perm("...")`
  - `require_perm('...')`
- Extract permission codes as strings (e.g., `Bill.Print`)
- Print a report to stdout with three sections:

1) `ALL_CODES` (sorted unique, one per line)
2) `ADMIN_MISSING` (codes present in ALL_CODES but missing from ROLE_PERMISSIONS["Admin"])
3) `ROLE_MISSING` (for each role != Admin, list missing codes) — REPORT ONLY

The script must exit with code 0.

### B) Patch Admin permission list (seed source-of-truth)
Locate `ROLE_PERMISSIONS` dict used by `seed_default_roles_perms(db)`.
- Update ONLY `ROLE_PERMISSIONS["Admin"]` so it includes ALL permission codes in ALL_CODES.
- Preserve existing items; append missing items in sorted order.
- Do NOT modify other roles.
