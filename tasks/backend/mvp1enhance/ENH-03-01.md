
# ENH-03-01 — Create Pydantic Schemas for Billing Endpoints

## Goal
Create Pydantic schemas for all billing-related endpoints to ensure data validation and automatic OpenAPI documentation.

## Scope
- Modify **ONLY** `schemas.py` to define the Pydantic schemas for billing endpoints such as bill creation, payment, and status transitions.

## Required Steps
1) In `schemas.py`, define Pydantic models for:
   - `BillCreateSchema`: For creating new bills.
   - `BillUpdateSchema`: For updating bill details.
   - `PaymentSchema`: For handling payments.
   - `BillStatusSchema`: For updating bill status.
2) Ensure all fields are validated and use appropriate types (e.g., `Decimal` for amounts).

## Acceptance Criteria
- [ ] Pydantic schemas are correctly defined and validated.
- [ ] No `dict[str, Any]` is used in the endpoints.

## Evidence Required
- `ruff check` and `python3 -m py_compile` outputs for `schemas.py`.
- `git diff` showing only changes in `schemas.py`.

## Verification
```bash
cd backend
ruff check app/modules/billing/schemas.py
ruff format app/modules/billing/schemas.py
python3 -m py_compile app/modules/billing/schemas.py
cd ..
```
