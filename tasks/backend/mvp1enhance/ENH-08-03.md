## Required implementation (EXACT)

### Functions (must exist; names may vary but API tasks will call them)
1) `list_templates(db, *, filters: dict, page: int, page_size: int) -> tuple[list[Template], int]`
   - Filters supported (if columns exist): `group`, `language`, `enabled`
   - Order by most-recent (created_at desc or updated_at desc if present)

2) `get_template(db, *, template_id: str) -> Template`
   - NOT_FOUND BusinessError if missing

3) `create_template(db, *, data: TemplateCreateIn, actor_id: str | None) -> Template`
   - If Template PK is UUID string and model has no default generator, set `id=str(uuid4())`
   - Insert row with fields from schema
   - Commit and refresh

4) `update_template(db, *, template_id: str, data: TemplateUpdateIn, actor_id: str | None) -> Template`
   - Load existing template
   - Update only provided fields (`exclude_unset=True`)
   - Commit and refresh

### Constraints

- Do NOT invent new DB columns.
