# ENH-01-11 — Relocate T_RolePerm to auth/models.py (align with existing T_Role) and keep rbac/models.py as shim

## Context / Why (Authoritative)
Repo fact: `T_Role` is defined in `backend/app/modules/auth/models.py` (table `t_role`).
ENH-01-01 originally added `T_RolePerm` into `backend/app/modules/rbac/models.py`, which conflicts with the prerequisite assumption (“T_Role exists in same file”) and risks model/metadata inconsistency.

We adopt **Route B1**:
- Keep `T_Role` in auth module.
- Define `T_RolePerm` alongside `T_Role` in `auth/models.py`.
- Keep `rbac/models.py` as a **thin re-export shim** to preserve any imports without duplicating ORM model definitions.

## Target (Atomic – FIXED)
- Move the ORM definition of `T_RolePerm` to `backend/app/modules/auth/models.py`.
- Remove the ORM definition from `backend/app/modules/rbac/models.py` and replace with a shim import/re-export.
- No migrations in this task (handled separately).

## Allowed files (Strict allowlist)
- `backend/app/modules/auth/models.py`
- `backend/app/modules/rbac/models.py`

## Non-scope (explicitly excluded)
- Alembic migrations
- Changing any endpoints/routers
- Changing auth/RBAC behavior (require_perm, permission resolution, etc.)
- Seed changes
- New dependencies

## Implementation requirements (EXACT)
1) In `backend/app/modules/auth/models.py`:
   - Add/ensure `T_RolePerm` ORM model definition exists there (single authoritative definition).
   - The model must match ENH-01-01 spec and UUID/TEXT PK decision:
     - `id`: UUID/TEXT (`String(36)`), generated app-side (`uuid4()`).
     - `role_id`: FK references `t_role.id` and type matches `T_Role.id`.
     - `created_at`: SQLite-safe default `CURRENT_TIMESTAMP`.
     - Unique constraint name exactly `uq_role_perm` on (`role_id`, `perm_code`).

2) In `backend/app/modules/rbac/models.py`:
   - Remove ORM class definition of `T_RolePerm` (avoid duplicate model definition).
   - Replace file contents with minimal shim re-exporting from auth module:
     ```python
     from __future__ import annotations
     from app.modules.auth.models import T_RolePerm  # re-export
     __all__ = ["T_RolePerm"]
     ```
   - Do NOT define any SQLAlchemy Base or tables in this shim.
