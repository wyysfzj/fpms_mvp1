# ENH-10-01 — Add DB Mixins for UUID PK + Audit Fields

**Category**: Cross-Cutting Enhancements → Database  
**Source**: `mvp1_backend_review_report.md` §6.2 Database (Item 10.5)  
**Priority**: P0

## Goal

Create a single, reusable set of SQLAlchemy mixins to standardize:

- **UUID string primary keys** (`id`)
- **Audit timestamps** (`created_at`, `updated_at`)
- Optional **audit actor fields** (`created_by`, `updated_by`) as lightweight string UUIDs

This directly prevents recurring runtime failures like “PK has no default generator” (e.g., `NOT NULL constraint failed: t_client.id`) by providing a consistent default UUID generator.

## Required Implementation Details

Implement **SQLAlchemy 2.x** mixins using `Mapped` + `mapped_column`:

### `UUIDPrimaryKeyMixin`
- Adds column:
  - `id`: UUID string (`VARCHAR(36)` or equivalent), `primary_key=True`
  - Default generator: `uuid.uuid4()` converted to `str`

### `AuditMixin`
- Adds:
  - `created_at`: timezone-aware `datetime`, default now (UTC)
  - `updated_at`: timezone-aware `datetime`, default now (UTC), auto-updated on update
  - `created_by`: nullable string UUID (no FK enforcement in MVP1)
  - `updated_by`: nullable string UUID (no FK enforcement in MVP1)

Notes:
- Prefer **Python-side defaults** for compatibility with SQLite.
- Keep the implementation minimal and dependency-free (only stdlib + SQLAlchemy).
