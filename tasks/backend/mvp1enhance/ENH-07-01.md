### Schemas to define

   - `is_active` optional only if DB has default; otherwise required per NOT NULL

2) `ClientUpdateIn`
   - All fields optional (exclude unset used in service)
   - Must NOT allow changing `id`, `created_at`, `updated_at`

3) `ClientOut` (ORM)
   - `id`, all core fields, `is_active`, `created_at`, `updated_at`
   - Use `ConfigDict(from_attributes=True)`

4) `ClientListItemOut`
   - Minimal list projection: `id`, `client_code`, `name_cn`, `name_en`

5) `OkOut` (if not already in module)
   - `status: str = "ok"`
