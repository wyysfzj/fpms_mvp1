## Scope decision (MVP1 – FIXED)
- This task defines the **core fee data model** for MVP1.
- Fee calculation logic, billing logic, and APIs are OUT OF SCOPE.

## Models to implement (EXACT)

### T_FeeRate
Fields:
- `id`
- `fee_code`
- `fee_name`
- `fee_type`
- `currency`
- `default_amount`
- `enabled`

Rules:
- `fee_type` MUST be one of:
  - `GOV`
  - `SERVICE`
  - `MISC`
- Store `fee_type` as a string enum (no free-text values)

### T_FeeDraft
Fields:
- `id`
- `case_id` (FK → `T_Case.id`)
- `client_id` (FK → `T_Client.id`)
- `draft_type`
- `currency`
- `status`
- `total_gov`
- `total_service`
- `total_misc`
- `amount`
- `created_at`
- `updated_at`

Rules:
- All total fields (`total_gov`, `total_service`, `total_misc`, `amount`) are:
  - REQUIRED
  - Non-null
- `status` is a string field (values enforced at service layer, not here)

### T_FeeItem
Fields:
- `id`
- `draft_id` (FK → `T_FeeDraft.id`)
- `case_id` (FK → `T_Case.id`)
- `rate_id` (FK → `T_FeeRate.id`)
- `fee_code`
- `fee_name`
- `fee_type`
- `year_no`
- `quantity`
- `unit_price`
- `amount`
- `remark`

Rules:
- `fee_type` MUST be one of:
  - `GOV`
  - `SERVICE`
  - `MISC`
- `year_no`:
  - MUST exist as a column
  - MAY be NULL
- `amount`:
  - REQUIRED
  - Non-null
- No derived fields in this task
