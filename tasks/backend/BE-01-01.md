# BE-01-01 — RBAC models (User/Role/UserRole)

## Design references
- `backend/app/modules/auth/docs/auth_00_overview.md`

## Target
- **File:** `backend/app/modules/auth/models.py`
- **Atomic rule:** modify/create ONLY this file; implement ONLY what is described below.

## Scope decision (MVP1 – FIXED)
- This task implements the **exact MVP1 data model** defined in `auth_00_overview.md`.
- No additional fields are allowed.
- No APIs are implemented in this task.

## Models to implement (EXACT)

### T_User
Fields (MVP1):
- `id`
- `username` (unique)
- `display_name`
- `password_hash`
- `is_active`
- `created_at`
- `updated_at`

Rules:
- `display_name` **MUST be included**
- Audit fields in MVP1 mean **ONLY**:
  - `created_at`
  - `updated_at`
- Do **NOT** add `created_by` / `updated_by`
- Do **NOT** add any other audit or profile fields

### T_Role
Fields:
- `id`
- `code` (unique)
- `name`

### T_UserRole
Fields:
- `user_id` (FK → `T_User.id`)
- `role_id` (FK → `T_Role.id`)

Rules:
- Composite primary key: (`user_id`, `role_id`)
- No additional columns

## Non-scope (explicitly excluded)
- No permission tables (`T_RolePerm`)
- No API routes
- No seed data
- No RBAC logic
- No relationships beyond basic foreign keys
