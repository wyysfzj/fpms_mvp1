# FPMS 客户 Demo 操作手册 v2

## 0. 演示定位

这份 v2 runbook 是给现场演示人员使用的操作手册，不是测试报告。它把已经验证过的 FPMS full-case-lifecycle 串成一条客户能理解的业务主线：

新建国内发明案件 -> 登记申请材料 -> 批量递交 -> 官方回执 -> OA 来文 -> OA 答复 -> 授权通知 -> 授权费任务 -> 授权费通知函 -> 授权费草稿 -> 官费清单 -> 账单 -> 回款核销 -> 授权后状态 -> 年费任务 -> 提成记录 -> 提成结算。

所有业务状态变更都必须通过真实前端页面可见 UI 完成：点击、输入、选择、提交、确认、筛选、导航。

### 当前导航口径

产品侧栏已切换为生产 UI 导航。演示主线默认使用“工作导航”，该模式按端到端业务流展示：

- “我的工作”：工作台、今日提醒、任务与期限、专项期限检索。
- “案件生命周期”：案件列表、新建案件、往来文件、案件批量递交。
- “费用到回款”：授权费任务、费用草稿、官费清单、账单管理、回款与核销、个案收款登记。
- “授权后运营”：年费任务、催款管理、提成记录、提成结算。
- “管理入口”：客户管理、报表总览、系统配置，位于侧栏底部。

如果现场看到侧栏已收起，先点击侧栏顶部“展开侧栏”；如果某个大功能分组已折叠，先展开对应分组后再点击菜单项。只有需要按传统模块查找时才切换到“模块导航”。

## 2. 操作手册

### 第 0 步：登录并确认演示环境

- 进入方式：打开 FPMS 前端地址，进入登录页。
- 字段与数据：使用已准备好的演示账号登录；不要在文档或现场屏幕上展示密码。
- 点击按钮：点击“登录”。
- 可观察关键状态：进入工作台，左侧侧栏默认停留在“工作导航”；能看到“我的工作”“案件生命周期”“费用到回款”“授权后运营”等大功能分组。
- 继续条件：登录账号具备完整业务权限。
- 不满足时处理：如果跳回登录页，重新登录；如果菜单缺失，换完整权限演示账号。
- 业务状态变更：是，建立登录会话；不产生案件业务数据。

### 第 1 步：新建国内发明案件

- 进入方式：左侧侧栏选择“工作导航”，展开“案件生命周期”，点击“新建案件”；也可以先点击“案件列表”，再在案件列表页点击“新建案件”或“新增案件”按钮。
- 字段与数据：
  - 案件类型：选择“国内发明”。
  - 案件编号：输入 `DEMO-RUI-20260510A-001`。
  - 发明名称：输入 `演示用智能水务数据处理方法`。
  - 国家/地区：选择“中国”。
  - 币种：选择或保留 `CNY`。
- 点击按钮：先不要保存，继续完成客户和申请人。
- 可观察关键状态：新建案件表单中可见案件编号、案件类型、发明名称。
- 继续条件：案件编号不能与历史数据重复。
- 不满足时处理：如果提示案号重复，在案号后追加当天序号，例如 `-002`。
- 业务状态变更：否，当前仍是表单草稿。

### 第 2 步：在新案表单中创建或选择客户

- 进入方式：仍在新建案件表单，定位到“客户”字段。
- 字段与数据：
  - 客户名称：`演示客户科技有限公司20260510A`。
  - 客户类型、地区、币种等按页面必填项选择演示值。
- 点击按钮：点击客户字段旁的“新增/快速创建/选择客户”入口；填写后点击“确定/保存”；回到案件表单后选择该客户。
- 可观察关键状态：案件表单的客户字段显示 `演示客户科技有限公司20260510A`。
- 继续条件：客户字段已回填到案件表单。
- 不满足时处理：如果快速创建没有回填，打开客户选择框，按客户名称筛选后手动选择。
- 业务状态变更：是，创建或关联客户主数据。

### 第 3 步：在新案表单中创建或选择申请人

- 进入方式：仍在新建案件表单，定位到“申请人”或“申请人信息”区域。
- 字段与数据：
  - 申请人名称：`演示申请人创新中心20260510A`。
  - 申请人类型、国家/地区等按页面必填项选择演示值。
- 点击按钮：点击“新增申请人/快速创建/选择申请人”；填写后点击“确定/保存”；回到案件表单后添加为第一申请人。
- 可观察关键状态：申请人区域显示 `演示申请人创新中心20260510A`。
- 继续条件：至少有一个申请人，且主申请人或第一申请人可见。
- 不满足时处理：如果申请人未显示，重新打开申请人选择框，按名称筛选并添加。
- 业务状态变更：是，创建或关联申请人主数据。

### 第 4 步：保存案件并进入案件详情

- 进入方式：新建案件表单底部或顶部操作区。
- 字段与数据：确认案件编号、案件类型、发明名称、客户、申请人均已填写。
- 点击按钮：点击“保存”或“提交”。
- 可观察关键状态：
  - 页面跳转到案件详情，或列表中可按案号找到该案。
  - 案件详情显示案号、客户、申请人、发明名称。
  - 案件状态通常为“未递交”或受理前状态。
- 继续条件：案件详情页可见。
- 不满足时处理：根据表单校验提示补齐必填字段；不要跳过校验。
- 业务状态变更：是，创建案件主记录和案件申请人关系。

### 第 5 步：登记申请请求书

- 进入方式：案件详情页，点击“文书/文件/往来文件”页签或“登记往来文件”按钮。
- 字段与数据：
  - 文档方向：选择“客户来文”。
  - 文档类型/模板：选择“申请请求书”。
  - 文档名称：输入 `申请请求书-DEMO-20260510A`。
  - 案件：保持当前案件。
- 点击按钮：点击“保存”或“提交”。
- 可观察关键状态：文书列表中可见 `申请请求书-DEMO-20260510A`。
- 继续条件：该材料在当前案件文书列表可见。
- 不满足时处理：如果没有出现在列表，刷新案件文书页签；仍无则重新登记。
- 业务状态变更：是，登记案件材料。

### 第 6 步：登记说明书

- 进入方式：案件详情页，点击“登记往来文件”。
- 字段与数据：
  - 文档方向：客户来文。
  - 文档类型/模板：说明书。
  - 文档名称：`说明书-DEMO-20260510A`。
- 点击按钮：点击“保存”或“提交”。
- 可观察关键状态：文书列表中可见说明书。
- 继续条件：说明书挂在同一案件下。
- 不满足时处理：检查登记时是否选择了当前案件。
- 业务状态变更：是。

### 第 7 步：登记权利要求书

- 进入方式：案件详情页，点击“登记往来文件”。
- 字段与数据：
  - 文档方向：客户来文。
  - 文档类型/模板：权利要求书。
  - 文档名称：`权利要求书-DEMO-20260510A`。
- 点击按钮：点击“保存”或“提交”。
- 可观察关键状态：文书列表中可见权利要求书。
- 继续条件：权利要求书挂在同一案件下。
- 不满足时处理：按页面提示补齐文档名称、方向、类型。
- 业务状态变更：是。

### 第 8 步：登记摘要并确认材料 gate

- 进入方式：案件详情页，点击“登记往来文件”。
- 字段与数据：
  - 文档方向：客户来文。
  - 文档类型/模板：摘要。
  - 文档名称：`摘要-DEMO-20260510A`。
- 点击按钮：点击“保存”或“提交”；保存后回到案件文书列表。
- 可观察关键状态：申请请求书、说明书、权利要求书、摘要四类材料均可见。
- 继续条件：材料 gate 不再提示缺失硬性材料。
- 不满足时处理：按缺失材料名称补登记；不能强行进入批量递交。
- 业务状态变更：是。

### 第 9 步：批量递交当前案件

- 进入方式：左侧侧栏选择“工作导航”，展开“案件生命周期”，点击“案件批量递交”。
- 字段与数据：
  - 筛选字段：案件编号。
  - 筛选值：`DEMO-RUI-20260510A-001`。
- 点击按钮：点击“查询/筛选”；勾选当前案件；点击“批量递交/递交”；在确认框点击“确认”。
- 可观察关键状态：
  - 页面提示提交成功，或当前案离开未递交候选列表。
  - 回到案件详情后状态显示“等待受理/等待回执/递交后”等同义状态。
- 继续条件：案件已离开未递交状态。
- 不满足时处理：如果无法勾选，回案件详情检查材料 gate 和案件状态。
- 业务状态变更：是，案件进入递交后阶段。

### 第 10 步：登记官方受理通知或回执

- 进入方式：回到案件详情，点击“登记往来文件”。
- 字段与数据：
  - 文档方向：官方来文。
  - 文档类型/模板：受理通知或官方回执。
  - 文档名称：`受理通知书-DEMO-20260510A`。
  - 申请号：如页面有字段，输入 `CN-DEMO-20260510A`。
- 点击按钮：点击“保存/提交”。
- 可观察关键状态：受理通知文档可见；案件处于官方处理链路。
- 继续条件：官方回执保存成功。
- 不满足时处理：如果文档类型不可选，说明演示环境需要预配置文档模板。
- 业务状态变更：是，登记官方回执。

### 第 11 步：登记 OA 来文并触发答复任务

- 进入方式：案件详情页点击“登记往来文件”。
- 字段与数据：
  - 文档方向：官方来文。
  - 文档类型/模板：OA / 审查意见通知书。
  - 文档名称：`第一次审查意见通知书-DEMO-20260510A`。
  - 是否需要答复：选择“是”。
  - 官方绝限：选择演示当天后 60 天。
  - 摘要：输入“演示 OA 来文，需要答复”。
- 点击按钮：点击“保存/提交”。
- 可观察关键状态：OA 文档保存成功。
- 继续条件：OA 文档在当前案下可见。
- 不满足时处理：如果提示缺少绝限或摘要，补齐后再保存。
- 业务状态变更：是，登记 OA 来文并触发任务生成规则。

### 第 12 步：观察 OA_REPLY 任务

- 进入方式：案件详情页点击“任务”页签；必要时点击“刷新”。
- 字段与数据：无需输入。
- 点击按钮：点击“任务”页签或“刷新”。
- 可观察关键状态：任务列表出现 OA 答复、OA_REPLY、答复期限或同义任务，状态为未完成/待处理。
- 继续条件：OA 答复任务可见。
- 不满足时处理：刷新任务页签；仍没有则说明任务模板或 OA 类型配置需检查。
- 业务状态变更：否，观察系统自动生成任务。

### 第 13 步：登记 OA 答复并核销任务

- 进入方式：案件详情页点击“登记往来文件”。
- 字段与数据：
  - 文档方向：官方去文或对外文件。
  - 文档类型/模板：OA_REPLY / OA 答复。
  - 文档名称：`第一次审查意见答复-DEMO-20260510A`。
  - 关联来文：选择 `第一次审查意见通知书-DEMO-20260510A`。
  - 答复日期：选择演示当天。
- 点击按钮：点击“保存/提交”。
- 可观察关键状态：
  - OA 答复文档保存成功。
  - 回到任务页签后，OA 答复任务显示已完成、已核销或同义状态。
- 继续条件：任务完成状态可见。
- 不满足时处理：如果无法关联来文，确认 OA 来文和答复文件属于同一案件。
- 业务状态变更：是，登记答复并完成/核销任务。

### 第 14 步：补齐授权字段

- 进入方式：案件详情点击“编辑”或“编辑案件”。
- 字段与数据：
  - 申请号：`CN-DEMO-20260510A`。
  - 公开号：`PUB-DEMO-20260510A`。
  - 授权号：`GR-DEMO-20260510A`。
  - 专利号：`ZL-DEMO-20260510A`。
  - 授权日：演示当天。
  - 有效期至：演示当天后 20 年。
  - 首年年费年度：`1`。
- 点击按钮：点击“保存”。
- 可观察关键状态：案件详情显示授权元数据或相关字段。
- 继续条件：授权字段保存成功。
- 不满足时处理：如果字段不在当前表单，查找“授权信息/专利信息/年费信息”区域。
- 业务状态变更：是，补齐授权和年费初始化前置字段。

### 第 15 步：登记授权通知

- 进入方式：案件详情点击“登记往来文件”。
- 字段与数据：
  - 文档方向：官方来文。
  - 文档类型/模板：GRANT_NOTICE / 授权通知。
  - 文档名称：`授权通知书-DEMO-20260510A`。
  - 授权日、授权号、专利号、有效期、首年年费年度：按 Step 14 数据填写或确认带出。
- 点击按钮：点击“保存/提交”。
- 可观察关键状态：案件详情出现“待授权/授权/授权费”等状态或关键词。
- 继续条件：授权通知保存成功，授权相关状态可见。
- 不满足时处理：如果提示缺字段，回 Step 14 补齐。
- 业务状态变更：是，案件进入授权相关阶段，并触发授权费任务。

### 第 16 步：筛选授权费任务

- 进入方式：左侧侧栏选择“工作导航”，展开“费用到回款”，点击“授权费任务”。
- 字段与数据：
  - 案件编号筛选：`DEMO-RUI-20260510A-001`。
- 点击按钮：点击“查询/筛选”。
- 可观察关键状态：列表出现当前案件授权费任务。
- 继续条件：目标授权费任务可见。
- 不满足时处理：刷新后重新筛选；仍无则检查授权通知和任务模板。
- 业务状态变更：否。

### 第 17 步：生成授权费通知函

- 进入方式：授权费任务页，保持当前案号筛选结果。
- 字段与数据：勾选当前案件授权费任务。
- 点击按钮：点击“批量生成通知函”；确认框点击“确认”。
- 可观察关键状态：页面提示生成成功；通知状态、通知次数或内部已通知状态更新。
- 继续条件：不再出现模板未配置错误，通知状态可见。
- 不满足时处理：如果提示模板未配置，说明 `GRANT_FEE_NOTICE` 模板前置未满足，切换已配置环境。
- 业务状态变更：是，生成授权费通知文件并更新授权费任务通知状态。

### 第 18 步：记录客户支付指示

- 进入方式：授权费任务页，勾选或定位当前任务行。
- 字段与数据：
  - 客户指示：选择或标记为“支付”。
- 点击按钮：点击“批量标记支付/标记支付/保存指示”。
- 可观察关键状态：客户指示列显示“支付”，任务进入可生成草稿状态。
- 继续条件：客户指示为支付。
- 不满足时处理：如果按钮不可用，确认任务未完成且未生成草稿。
- 业务状态变更：是，记录客户支付授权费指示。

### 第 19 步：生成授权费草稿

- 进入方式：授权费任务页当前任务行。

- 不满足时处理：如果没有官费行，说明当前草稿没有官方费用，可解释后直接进入账单步骤。

## 4. 演示风险处理表

| 风险 | 现场表现 | 推荐处理 |
| --- | --- | --- |
| 找不到新建案件按钮 | 案件列表无“新建”入口。 | 切换有案件创建权限的演示账号。 |
| 材料 gate 不通过 | 批量递交页无法勾选案件。 | 回案件详情补登记缺失材料，并解释系统做递交前风控。 |
| OA_REPLY 任务未出现 | 任务页签无 OA 答复任务。 | 刷新任务页签；仍无则说明 OA 文档类型或任务模板未配置。 |
| 授权费任务未出现 | 授权费任务页按案号筛选为空。 | 检查授权通知是否保存、授权字段是否完整。 |
| 授权费通知函模板缺失 | 生成通知函时报模板错误。 | 说明通知函依赖模板配置，切换已配置演示环境。 |
| 费用草稿按案号筛选为空 | 费用草稿页找不到记录。 | 用草稿编号或重置筛选后从最近生成记录进入。 |
| 官费清单按钮不可用 | 草稿详情无可勾选官费行。 | 说明该草稿没有官费项，改走服务费账单演示。 |
| 账单详情未显示最新内容 | 页面旧状态或短暂错误。 | 点击刷新，或从账单列表重新进入。 |
| 回款无法核销到账单 | 核销弹窗无目标账单。 | 确认客户、币种一致，账单仍有余额。 |
| 年费任务为空 | 授权后没有年费任务。 | 说明依赖年费监控、有效期和首年年费年度。 |
| 提成记录为空 | 提成记录页无结果。 | 说明提成依赖服务费、回款比例和阶段规则；使用已满足条件演示数据。 |

## 5. 收尾检查

现场收尾前，建议让客户看到这 6 个可观察状态：

1. 案件详情：案件编号、客户、申请人、授权后状态。
2. 任务页签：OA_REPLY 已完成或已核销。
3. 授权费任务页：当前案授权费任务已完成。
4. 账单详情或案件“账单与收款”：当前案账单与收款可见。
5. 年费任务页：当前案年费任务可见。
6. 提成结算页：当前案提成结算明细可见。
