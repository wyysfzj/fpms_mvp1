# FPMS 客户 Demo 现场速查 Checklist v2

## 演示前

- [ ] 前端和后端服务已启动。
- [ ] 演示账号具备案件、文书、任务、费用、账单、回款、授权费、年费、提成权限。
- [ ] 文档模板、任务模板、授权费通知函模板、费率、提成规则已在演示环境准备好。
- [ ] 使用虚构 run id，例如 `20260510A`。
- [ ] 不展示或记录密码、token、真实客户信息。
- [ ] 侧栏处于展开状态，并停留在“工作导航”。如分组已折叠，先展开对应大功能分组。

## 当前导航分组

- 我的工作：工作台、今日提醒、任务与期限、专项期限检索。
- 案件生命周期：案件列表、新建案件、往来文件、案件批量递交。
- 费用到回款：授权费任务、费用草稿、官费清单、账单管理、回款与核销、个案收款登记。
- 授权后运营：年费任务、催款管理、提成记录、提成结算。
- 管理入口：客户管理、报表总览、系统配置。
